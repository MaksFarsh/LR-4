# Домашнее задание к работе №4

## 1. Алгоритм

1. Начало
2. Ввод данных: A — номер кнопки первого игрока (вводит пользователь), B — номер кнопки второго игрока (вводит пользователь).
3. Вычислить результат раунда: победа засчитывается, если ровно один из игроков нажал на кнопку с четным номером. 
   * *Условие победы:* (A четное И B нечетное) ИЛИ (A нечетное И B четное).
   * В языке C это реализуется через оператор исключающего ИЛИ (XOR) или логическое неравенство: `result = ((A % 2 == 0) ^ (B % 2 == 0));`
4. Вывести результат (1 — победа, 0 — поражение).
5. Конец
### Блок-схема
```mermaid

    Start((Начало)) --> InputA[/Ввод A/]

    Condition -- Нет --> SetResult0[result = 0]

```
## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>
#define _CRT_SECURE_NO_WARNINGS

void main() {
    setlocale(LC_ALL, "RUS");
    int A, B, result;
    
    puts("Какую кнопку нажал первый игрок (A)?");
    scanf("%d", &A);
    
    puts("Какую кнопку нажал второй игрок (B)?");
    scanf("%d", &B);
    
    // Условие "ровно один четный" реализуется через XOR (исключающее ИЛИ)
    result = ((A % 2 == 0) ^ (B % 2 == 0));
    
    printf("Результат телевикторины (1 - победа, 0 - поражение): %d", result);
}
```
